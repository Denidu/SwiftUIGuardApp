# SwiftUI GuardApp

SwiftUI GuardApp is a SwiftUI-based application that integrates biometric authentication and real-time face detection to provide a secure app locking experience. It demonstrates how to use LocalAuthentication, Vision, and AVFoundation frameworks within a modern MVVM architecture.

## Features

- Face ID and biometric authentication using LocalAuthentication
- Real-time face detection using Vision and AVFoundation
- Secure lock screen interface
- SwiftUI-first implementation with MVVM design pattern
- Modular code structure with clean separation of concerns

## Getting Started

### Requirements

- iOS 16 or later
- Xcode 15 or later
- A real iOS device (camera and biometric features are not available in the simulator)

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/SwiftUIGuardApp.git
   cd SwiftUIGuardApp
2. Open the project in Xcode.

3. Build and run the app on a real iPhone device.
